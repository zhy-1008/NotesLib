# 1. 项目背景

## 1.1 项目定位

NotesLib 是一个：

- 单用户
- 本地运行
- CLI交互式

的个人知识管理工具。

核心目标：

解决：

- Markdown 文件管理混乱
- 笔记查找困难
- 标签管理缺失
- 大量笔记搜索效率低

问题。

> 构建一个本地 Markdown 知识库系统，通过 CLI 管理笔记，SQLite 保存元数据，磁盘保存倒排索引，实现快速全文搜索。
