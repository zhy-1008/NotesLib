# 文件核心

+ 实现对象Note来表示一篇笔记。

+ 将Note设计为领域模型，将程序中的对象对应为真实业务的概念。

+ 将Note拆分为MetaData和NoteContent两部分。

+ 将MetaData代表用户的一篇笔记，对于：

  ```
  MetaData
  
  id:
  1001
  
  title:
  C++ Memory Management
  
  location:
  notes/cpp_memory.md
  
  created:
  2026-07-31
  
  modified:
  2026-07-31
  
  tags:
  [c++, memory]
  ```

+ 在MetaData中并没有文本，因为设计的是**延迟加载内容**，所有MetaData只负责描述。
+ 而NoteContent则在用户需要时加载到内存中，这样可以在未来支持缓存功能。
