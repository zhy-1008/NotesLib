# 第一版本

## 1.笔记管理

+ 创建笔记

  ```
  new dir/filename
  ```

  生成：

  ```
  dir/filename.md
  ```

+ 修改笔记

  ```
  edit dir/filename
  ```

  运行之后打开文件 `dir/filename.md`

+ 删除笔记

  ```
  delete dir/filename
  ```

  删除文件，同时更新索引。

## 2.Markdown Parser（文件解析）

解析文件：

```
---
title:filename
tags:
	- cpp
	- stl
date:2026-7-30
---

content...
```

提取信息：

```
NoteMetadata
{
	title,
	tags,
	created_time,
	modified_time
}
```

## 3.SQlite 元数据数据库

数据库：`notes.db`

|   字段   |   意义   |
| :------: | :------: |
|    id    |   主键   |
|   path   | 文件路径 |
|  title   |   标题   |
| created  | 创建时间 |
| modified | 修改时间 |

## 4.标签系统

+ 标签通过数据库存放

+ 支持：

  ```
  search -tag cpp
  ```

  查找
